# Common Buff Spell Effects

This page records **table guidance** for frequently confused buff interactions. For exact spell text, use Archives of Nethys.

## Guidance

**Guidance** grants a status bonus to a single qualifying roll chosen by the target. Because it is a status bonus, it does not stack with another status bonus to the same roll.

Use the current spell entry on Archives of Nethys for the exact duration, immunity, traits, and targeting rules.

## Courageous Anthem

[Courageous Anthem](Spells/Inspire%20Courage%20%28Courageous%20Anthem%29.md) grants a status bonus to attacks, damage, and saves against fear. It does not improve unrelated saving throws or skill checks.

Because Guidance and Courageous Anthem both grant **status bonuses**, only the higher applicable status bonus affects a given roll.

### Table Example

If Seamus is using Courageous Anthem and another character casts Guidance on Mairi, Guidance is still useful for a roll that Courageous Anthem does not improve, such as an applicable skill check or non-fear saving throw. Spending Guidance on an attack already receiving the same status bonus from Courageous Anthem would not increase that attack further.

For spells that deal damage without an attack roll, check the current spell wording and the source of the damage bonus rather than assuming an attack bonus applies.
